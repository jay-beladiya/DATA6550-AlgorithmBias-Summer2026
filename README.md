# DATA6550 – Housing Discrimination and Algorithmic Bias Analysis

## Project Overview

This project investigates how historical housing discrimination may continue to influence modern mortgage lending outcomes in Hennepin County and Ramsey County, Minnesota. The analysis is divided into two main components:

- **Data Bias:** Examines the relationship between historical racial covenants and present-day housing characteristics, including property values, neighborhood income, and minority population.
- **Algorithmic Bias:** Investigates mortgage lending outcomes by analyzing loan approval rates, interest rates, and denial reasons across different applicant groups and covenant densities.

The project also includes an extension comparing lending patterns between Hennepin County and Ramsey County using the 2023 Minnesota HMDA dataset.

## Project Workflow

The project was completed in two phases.

### Part 1 – Data Bias
- Explored historical racial covenant data.
- Examined neighborhood demographics, property values, and income.
- Investigated how historical housing discrimination is reflected in present-day housing patterns.

### Part 2 – Algorithmic Bias
- Analyzed mortgage lending outcomes using the merged mortgage and covenant dataset.
- Compared loan approval rates across applicant racial groups.
- Examined interest rate distributions.
- Analyzed denial reasons for rejected applications.
- Extended the analysis by comparing Hennepin County and Ramsey County.

## Datasets

- **mortgage_covenant_data.csv** – Combined mortgage and historical covenant dataset used for the algorithmic bias analysis.
- **ramsey_covenants_geocoded.csv** – Historical covenant data for Ramsey County.
- **state_MN.csv** – 2023 Minnesota HMDA dataset used for the county comparison.
